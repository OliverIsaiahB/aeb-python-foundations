# Python Foundations for AI Agents

A from-scratch beginner project that teaches modern typed Python — type hints, dataclasses, enums, and async/await — by modeling the core of an AI agent evaluation system. The anchor is a tiny "agent run" you will grow into a full benchmarking platform later in the journey: a typed Task, an Agent that calls OpenAI, and a function that scores its answer.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- Python
- type hints
- dataclasses
- asyncio
- OpenAI
